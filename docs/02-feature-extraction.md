# 02 - 通用特征提取方法

## 设计动机

现有方法的特征提取存在两个问题：

1. **针对性太强**：不同数据集/工况需要设计不同的特征
2. **通用性不足**：难以跨电池类型、跨充放电协议使用

本文提出从**充电曲线**提取通用特征，解决泛化问题。

## 为什么选择充电曲线

```
放电过程                          充电过程
├── 用户特异（使用习惯不同）       ├── 固定且规范
├── 不一定完全放电                 ├── 大概率完全充电
├── 曲线形态多变                   ├── CC-CV模式普遍
└── 难以提取通用特征               └── 特征更具通用性
```

关键前提：大部分数据集的电池都采用 **CC-CV（恒流-恒压）充电模式**。

## 数据截取策略

### 电压区间

$$V \in [V_{end} - 0.2V, \ V_{end}]$$

- $V_{end}$：充电截止电压（如4.2V）
- 截取充电末段0.2V范围内的电压数据

### 电流区间

$$I \in [0.1A, \ 0.5A]$$

- 选择恒压充电阶段的电流数据
- 电流从高到低逐渐下降

### 截取示意

```
电压曲线                        电流曲线
    │                              │
V_end├────────────────        0.5A├────┐
    │        ╱                   │    │
    │      ╱                     │    ↓
V_end│   ╱                    0.1A├────┘
-0.2 │  ╱                        │
    └──────────→ time            └──────────→ time
    ↑                             ↑
    截取这段                       截取这段
```

## 16个统计特征

### 电压曲线特征（8个）

| 编号 | 特征名 | 数学定义 | 物理含义 |
|------|--------|----------|----------|
| 1 | mean | $\bar{V} = \frac{1}{N}\sum V_i$ | 平均充电电压 |
| 2 | std | $\sigma_V = \sqrt{\frac{1}{N}\sum(V_i-\bar{V})^2}$ | 电压波动程度 |
| 3 | kurtosis | 峰度 | 电压分布的尖锐程度 |
| 4 | skewness | 偏度 | 电压分布的不对称性 |
| 5 | charging time | $t_{end} - t_{start}$ | 充电时长 |
| 6 | accumulated charge | $\int I \cdot dt$ | 累积电荷量 |
| 7 | curve slope | $\frac{dV}{dt}$ | 电压变化斜率 |
| 8 | curve entropy | $-\sum p_i \log p_i$ | 电压分布复杂度 |

### 电流曲线特征（8个）

| 编号 | 特征名 | 物理含义 |
|------|--------|----------|
| 9 | mean | 平均充电电流 |
| 10 | std | 电流波动程度 |
| 11 | kurtosis | 电流分布的尖锐程度 |
| 12 | skewness | 电流分布的不对称性 |
| 13 | charging time | 恒压阶段时长 |
| 14 | accumulated charge | 恒压阶段电荷量 |
| 15 | curve slope | 电流衰减速率 |
| 16 | curve entropy | 电流分布复杂度 |

## 关键发现：特征-SOH相关性

论文计算了387个电池在4个数据集上的Pearson相关系数，发现：

> **特征与SOH的相关系数大小主要取决于电池化学体系，受充放电协议影响较小。**

```
LiNiCo-x 电池 (XJTU, TJU)    LiFePO4 电池 (HUST, MIT)
├── 特征相关性模式相似         ├── 特征相关性模式相似
├── 跨数据集可迁移             ├── 跨数据集可迁移
└── 化学体系决定特征表现       └── 化学体系决定特征表现
```

这个发现为跨数据集迁移学习提供了理论基础。

## 特征提取流程总结

```
原始充电数据
    │
    ▼
┌─────────────────────────────┐
│ 1. 截取电压区间 [V_end-0.2, V_end] │
│ 2. 截取电流区间 [0.1A, 0.5A]       │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────┐
│ 电压曲线: 8个统计特征              │
│ 电流曲线: 8个统计特征              │
│ 共 16 维特征向量                   │
└─────────────────────────────┘
    │
    ▼
输入PINN模型
```
