## 实验一：常规SOH估计

### 数据划分

```
训练集 : 验证集 : 测试集 ≈ 6 : 2 : 2

关键: 测试集电池在数据集中均匀分布
     (不是随机抽样，而是按比例选取)
```

### 主要结果

| 数据集 | Batch | PINN MAPE | MLP MAPE | CNN MAPE |
|--------|-------|-----------|----------|----------|
| XJTU | 1 | **0.70%** | 2.60% | 2.70% |
| XJTU | 2 | **1.13%** | 2.75% | 2.98% |
| XJTU | 3 | **0.86%** | 2.11% | 1.77% |
| XJTU | 4 | **0.71%** | 2.00% | 1.50% |
| TJU | - | **1.21%** | 1.72% | - |
| HUST | - | **0.65%** | 0.83% | - |
| MIT | - | **0.78%** | 0.83% | - |

### 关键发现

1. **PINN在所有数据集上都是最优**
2. **XJTU数据集上优势最明显**（样本量小，物理约束帮助大）
3. **HUST/MIT上差距较小**（数据量大，纯数据驱动也能学好）

### 稳定性分析（10次重复实验）

```
XJTU数据集 (小样本):
├── MLP/CNN: 波动大
└── PINN:    稳定，方差小

HUST/MIT数据集 (大样本):
├── MLP/CNN: 波动减小
└── PINN:    仍然最稳定
```

**结论**: PINN的稳定性优于纯数据驱动方法。

## 实验二：小样本学习

### 实验设计

```
训练集大小: 1 → 2 → 3 → 4 → 5 个电池
测试集: 固定不变
观察: 各方法性能随训练数据量的变化
```

### 结果（XJTU Batch 1）

| 训练电池数 | PINN MAPE | MLP MAPE | CNN MAPE |
|-----------|-----------|----------|----------|
| 1 | **1.5%** | 4.5% | 5.0% |
| 2 | **1.2%** | 3.5% | 3.8% |
| 3 | **1.0%** | 2.8% | 3.0% |
| 4 | **0.9%** | 2.6% | 2.7% |
| 5 | **0.8%** | 2.5% | 2.6% |

### 关键发现

1. **PINN用1个电池训练 ≈ MLP/CNN用3-4个电池训练**
2. 数据越少，PINN的优势越明显
3. 随着数据增加，差距缩小（但PINN始终最优）

## 实验三：迁移学习

### 实验设计

```
源域: 大量数据的数据集 (如XJTU)
目标域: 少量数据的数据集 (如TJU)

对比:
├── Source Only: 直接用源域模型测试
├── Direct Training: 用目标域数据直接训练
└── Fine-tuning: 源域预训练 + 目标域微调
```

### 迁移组合

| 源域 | 目标域 | 化学体系 | 预期效果 |
|------|--------|---------|---------|
| XJTU | TJU | NCM → NCA/NCM | 好（同族） |
| TJU | XJTU | NCA/NCM → NCM | 好（同族） |
| HUST | MIT | LFP → LFP | 好（同族） |
| MIT | HUST | LFP → LFP | 好（同族） |
| XJTU | HUST | NCM → LFP | 差（异族） |
| HUST | XJTU | LFP → NCM | 差（异族） |

### 关键结果

```
微调 vs 直接训练 (1个目标域电池):

方法                    MAPE
──────────────────────────────
Source Only            5.0%
Direct Training (1电池) 3.5%
Fine-tuning (1电池)    1.8%  ← 最优

结论: 1个电池微调 > 2个电池直接训练
```

### 迁移学习的发现

> **化学体系相近的数据集之间迁移效果更好**

```
NCM ↔ NCA (LiNiCo-x族)  →  迁移效果好
LFP ↔ LFP               →  迁移效果好
NCM ↔ LFP (不同族)       →  迁移效果差
```

这与特征提取部分的发现一致：特征-SOH相关性主要取决于化学体系。

## 总结：PINN的优势场景

| 场景 | PINN优势 | 原因 |
|------|---------|------|
| 小样本 | **显著** | 物理约束补偿数据不足 |
| 大样本 | 中等 | 数据驱动也能学好 |
| 跨协议迁移 | **显著** | G(Θ)学到通用动力学 |
| 跨化学体系迁移 | 有限 | F(Φ)需要重新适配 |
| 稳定性要求高 | **显著** | 物理约束减少波动 |
