# 04 - 三重损失函数

## 总览

$$L = L_{data} + \alpha \cdot L_{PDE} + \beta \cdot L_{mono}$$

```
损失函数
├── L_data:   数据拟合 ────→ 预测值接近真实值
├── L_PDE:    物理约束 ────→ 满足退化动力学方程
└── L_mono:   单调性约束 ──→ SOH随周期单调递减
```

## 1. 数据损失 L_data

### 公式

$$L_{data} = \sum_{i=1}^{N} |u_i - \hat{u}_i|^2$$

- $u_i$：第i个样本的真实SOH
- $\hat{u}_i$：第i个样本的预测SOH
- N：样本总数

### 作用

最基本的监督学习损失，让网络学会从特征预测SOH。

### 特点

- 标准MSE损失
- 不需要额外信息
- 纯数据驱动

## 2. PDE约束损失 L_PDE

### 公式

$$L_{PDE} = \sum_{i=1}^{N} |H(t_i, x_i)|^2$$

其中：

$$H = \frac{\partial F}{\partial t} - G(t, x, u, u_t, u_x) = 0$$

### 作用

**这是PINN的核心**——将物理知识注入模型。

```
物理世界:
  电池退化遵循动力学方程 du/dt = g(...)
  
PDE约束:
  强制网络预测满足这个方程
  → 模型不只是拟合数据，还要符合物理规律
```

### 为什么重要

| 没有PDE约束 | 有PDE约束 |
|------------|----------|
| 纯数据拟合 | 物理+数据联合驱动 |
| 需要大量数据 | 小样本也能学好 |
| 可能过拟合 | 泛化能力更强 |
| 预测可能违反物理规律 | 预测符合退化规律 |

### 物理意义

$$\frac{\partial u}{\partial t} = g(t, x, u, u_t, u_x)$$

这个方程描述了：**SOH随时间的变化率是当前状态(t, x, u)和梯度(u_t, u_x)的函数**。

网络学习的不是简单的映射，而是退化动力学本身。

## 3. 单调性损失 L_mono

### 公式

$$L_{mono} = \sum_{j=1}^{M} \sum_{k=1}^{N_j} \text{ReLU}(\hat{u}_{k+1} - \hat{u}_k)$$

- j：电池索引（共M个电池）
- k：第j个电池内的周期索引（共$N_j$个周期）
- ReLU：只惩罚违反单调性的情况

### 关键点：必须按电池分组

```
正确做法:                          错误做法:
电池A: u1 > u2 > u3 > ...         混合所有电池:
电池B: u1 > u2 > u3 > ...         按周期数排序后比较
电池C: u1 > u2 > u3 > ...         → 不同电池的SOH被比较
       ↓                               → 物理上无意义
每个电池内部独立验证单调性
```

### 作用

SOH的定义决定了它必须随周期单调递减：

```
周期:     1    2    3    4    5   ...
SOH:    1.0  0.98 0.96 0.94 0.92 ...
          ↓    ↓    ↓    ↓    ↓
        必须单调递减（物理规律）
```

### ReLU的设计

$$\text{ReLU}(\hat{u}_{k+1} - \hat{u}_k)$$

- 如果 $\hat{u}_{k+1} > \hat{u}_k$（违反单调性）→ 产生损失
- 如果 $\hat{u}_{k+1} \leq \hat{u}_k$（满足单调性）→ 损失为0

只惩罚违规，不强制严格递减（允许相等）。

## 三个损失的协作

```
训练过程中的平衡:

L_data   ───→  预测准确
   │
   │  α
   ▼
L_PDE    ───→  符合物理
   │
   │  β
   ▼
L_mono   ───→  单调递减

三者共同优化，找到平衡点
```

### 超参数选择

| 参数 | 作用 | 典型值 |
|------|------|--------|
| α | PDE损失权重 | 0.1 ~ 1.0 |
| β | 单调性损失权重 | 0.0 ~ 1.0 |

- α太大：过度约束，模型难以拟合数据
- α太小：物理约束弱，退化为纯数据驱动
- β太大：可能影响拟合精度
- β太小：单调性保证弱

## 总损失的代码实现

```python
def total_loss(predicted_u, true_u, H, cycle_indices, battery_ids, alpha=1.0, beta=1.0):
    L_data = data_loss(predicted_u, true_u)        # MSE
    L_pde = pde_loss(H)                            # PDE残差平方
    L_mono = monotonicity_loss(predicted_u,         # 按电池分组
                               cycle_indices, 
                               battery_ids)
    
    loss = L_data + alpha * L_pde + beta * L_mono
    
    return loss
```
