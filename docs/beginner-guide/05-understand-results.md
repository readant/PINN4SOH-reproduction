# 05 - 理解结果：模型预测了什么

> 学会解读实验结果，理解评估指标的含义

## 评估指标

### MAE（平均绝对误差）

```
MAE = (1/n) × Σ|ŷᵢ - yᵢ|
```

- 衡量预测值与真实值的平均偏差
- 越小越好
- 单位与目标变量相同（SOH 是无量纲的比值）

### MAPE（平均绝对百分比误差）

```
MAPE = (1/n) × Σ|ŷᵢ - yᵢ| / yᵢ × 100%
```

- 衡量相对误差
- **本文主要指标**
- 0.87% 表示平均预测偏差不到 1%

### MSE（均方误差）

```
MSE = (1/n) × Σ(ŷᵢ - yᵢ)²
```

- 训练时使用的目标函数
- 对大误差更敏感

### R²（决定系数）

```
R² = 1 - Σ(ŷᵢ - yᵢ)² / Σ(yᵢ - ȳ)²
```

- 衡量模型解释数据变异的能力
- 越接近 1 越好

### 关键发现

1. **PINN 在所有数据集上都优于 MLP 和 CNN**
   - 平均 MAPE 降低 30-40%

2. **物理约束的作用**
   - 单调性约束防止预测出现不合理的波动
   - PDE 约束确保预测符合退化动力学

3. **小样本场景优势更明显**
   - 仅用 1 个周期数据，PINN MAPE 仍 < 2%
   - MLP/CNN 需要 4+ 个周期才能达到类似精度

## 模型优缺点

### 优点

| 优点 | 说明 |
|------|------|
| 高精度 | MAPE 0.87%，满足工程需求 |
| 高稳定性 | 物理约束防止预测波动 |
| 小样本友好 | 仅需 1-4 个周期数据 |
| 跨数据集泛化 | 适用于不同化学体系和充放电协议 |

### 局限性

| 局限 | 说明 |
|------|------|
| 计算成本 | 比 MLP/CNN 稍高 |
| 超参数敏感 | α、β 需要手动调整 |
| 依赖充电数据 | 需要充满电前的数据段 |
| 无不确定性估计 | 只输出点估计，无置信区间 |
