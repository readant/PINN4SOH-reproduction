> 30 分钟快速了解这篇论文在做什么、为什么重要、结果如何

| 项目 | 内容 |

| **标题** | Physics-informed neural network for lithium-ion battery degradation stable modeling and prognosis |

## 研究问题

**核心问题**：如何准确、稳定地估计锂离子电池的健康状态（SOH）？

```
现实挑战
├── 电池类型多样（NCM、NCA、LFP 等不同化学体系）
├── 充放电协议各异（不同倍率、不同策略）
├── 数据获取困难（很少完全放电）
└── 现有方法局限
    ├── 物理模型：精确但计算复杂、泛化差
    └── 数据驱动：高效但不稳定、依赖特征工程
```

## 核心贡献（3 个创新点）

### 1. B2 架构 PINN

将电池退化动力学方程直接嵌入神经网络训练，实现**物理约束与数据驱动的真正融合**。

```
传统方法：物理模型 → 特征 → 神经网络（分离）
本文方法：物理方程 ←→ 神经网络（融合）
```

### 2. 通用特征提取方法

从**充满电前的一小段数据**中提取统计特征，适用于不同电池类型和充放电协议。

```
为什么选充电数据？
├── 放电过程因人而异（用户策略不同）
├── 充电过程相对固定（一旦开始，大概率充满）
└── 充满电前的数据在大多数数据集中都存在
```

### 3. 大规模验证

- 自建数据集：55 个 NCM 电池（XJTU 数据集）
- 跨数据集验证：4 个数据集，387 个电池，310,705 个样本
- 三类实验：常规实验、小样本实验、迁移学习实验

## 关键结果

### 整体性能

| 数据集 | 化学体系 | 电池数 | 论文报告 MAPE |
|--------|---------|--------|--------------|
| XJTU | NCM | 55 | 0.78% |
| HUST | LFP | 77 | 0.65% |
| MIT | LFP | 125 | 0.78% |
| TJU | NCA / NCM | 130 | 1.21% |
| **合计 / 平均** | | **387** | **0.87%** |

> 电池数为本仓库 `PINN4SOH/data/` 目录下的实际 CSV 文件数，合计 387，与论文口径一致。
> 表中 MAPE 为**论文报告值**；本仓库在本机环境下重新训练的实测值（平均 0.88%）
> 见 [05-understand-results.md](05-understand-results.md) 与 `PINN4SOH/results/SUMMARY.md`。

### 与基线方法对比（本仓库实测，仅 XJTU）

```
方法          XJTU MAPE
─────────────────────────
MLP           2.23%
CNN           2.53%
PINN          0.87%      ✓ 最优
```

> 基线（MLP / CNN）在本仓库**只跑了 XJTU**，故此处不列其它数据集。
> 具体数值与实验次数见 `PINN4SOH/results/SUMMARY.md`。

### 小样本学习

仅用 1-4 个周期的数据训练，PINN 仍能保持较高精度，远优于 MLP 和 CNN。

### 迁移学习

从一个数据集迁移到另一个数据集（如 TJU → XJTU），PINN 同样表现优异。

## 一句话总结

> PINN4SOH 通过将电池退化动力学方程嵌入神经网络，实现了物理约束与数据驱动的融合，在 4 个数据集 387 个电池上取得了 0.87% 的平均 MAPE，同时在小样本和迁移学习场景下也表现优异。
