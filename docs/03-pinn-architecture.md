# 03 - PINN模型架构

## 整体结构

```
                    ┌─────────────────────────────────────┐
                    │           PINN 模型                  │
                    │                                     │
   t (周期) ───────→│  ┌─────────────┐                    │
                    │  │ 解网络 F(Φ) │──→ u (预测SOH)     │
   x (16维特征) ──→│  └─────────────┘       │            │
                    │       │                 │            │
                    │       │ 自动微分         │            │
                    │       ▼                 │            │
                    │   u_t = ∂u/∂t           │            │
                    │   u_x = ∂u/∂x           │            │
                    │       │                 │            │
                    │       ▼                 │            │
                    │  ┌─────────────────┐    │            │
                    │  │ 动力学网络 G(Θ) │←───┘            │
                    │  └─────────────────┘                 │
                    │       │                              │
                    │       ▼                              │
                    │   g (退化速率)                        │
                    │       │                              │
                    │       ▼                              │
                    │   H = u_t - g = 0  ← PDE约束         │
                    └─────────────────────────────────────┘
```

## 两个子网络

### 解网络 F(Φ)

**作用**：建立特征到SOH的映射关系

$$u_i = f(t_i, x_i)$$

```
输入: t (1维) + x (16维) = 17维
  │
  ▼
全连接层 (64 → 64 → 32)
  │
  ▼
Sigmoid激活 → 输出 (0, 1)
  │
  ▼
输出: u (SOH预测值)
```

- 输出范围 (0, 1)，匹配SOH定义
- 网络结构：17 → 64 → 64 → 32 → 1

### 动力学网络 G(Θ)

**作用**：建模电池退化动力学

$$\frac{\partial u}{\partial t} = g(t, x, u, u_t, u_x; \Theta)$$

```
输入: t (1维) + x (16维) + u (1维) + u_t (1维) + u_x (16维) = 35维
  │
  ▼
全连接层 (64 → 64 → 32)
  │
  ▼
输出: g (SOH衰减速率)
```

- 输入包含梯度信息（u_t, u_x），这是PINN的核心特征
- 网络结构：35 → 64 → 64 → 32 → 1

## PDE约束的实现

### 约束方程

$$H := \frac{\partial F(t,x;\Phi)}{\partial t} - G(t,x,u,u_t,u_x;\Theta) = 0$$

### 自动微分计算梯度

```python
# PyTorch自动微分示例
u = F(t, x)                    # 解网络前向传播
u_t = ∂u/∂t                    # 对时间t求偏导
u_x = ∂u/∂x                    # 对特征x求偏导（16维）
g = G(t, x, u, u_t, u_x)       # 动力学网络
H = u_t - g                    # PDE残差
```

### 为什么只用一阶偏导

| 阶数 | 精度 | 计算复杂度 | 本文选择 |
|------|------|-----------|---------|
| 一阶 | 够用 | 低 | **选用** |
| 二阶 | 更高 | 高 | 未采用 |
| 更高阶 | 边际提升 | 很高 | 不必要 |

> 论文实验证明：一阶偏导数已经足够捕捉退化动力学。

## 模型的两种模式

### 全量训练模式

```
F(Φ): 可训练 ✓
G(Θ): 可训练 ✓

适用于: 初始训练、大数据集
```

### 微调模式

```
F(Φ): 可训练 ✓
G(Θ): 冻结 ✗

适用于: 迁移学习、小样本场景
```

微调模式的物理意义：
- G(Θ)学习的是**通用退化动力学**，与具体场景无关
- F(Φ)学习的是**特定场景的特征映射**，需要适配新数据
- 冻结G、微调F = 用通用物理知识 + 适配新场景

## 前向传播完整流程

```
输入: (t, x)
  │
  ├──→ F(t, x) = u          # 预测SOH
  │
  ├──→ ∂u/∂t = u_t          # 自动微分
  │
  ├──→ ∂u/∂x = u_x          # 自动微分
  │
  └──→ G(t, x, u, u_t, u_x) = g   # 退化速率
  
输出: (u, H=u_t-g, u_t, u_x)
```

训练时使用全部4个输出，推理时只用u。
