# 01 - 问题定义与研究动机

## 什么是SOH

**SOH (State of Health)** = 当前可用容量 / 初始额定容量

```
SOH = Q_current / Q_nominal × 100%
```

- SOH = 100%：电池满容量
- SOH = 80%：电池达到第一次服役寿命终点
- SOH < 80%：电池需退役或梯次利用

## 为什么需要估计SOH

```
锂电池应用场景
├── 电动汽车 ──→ 续航里程焦虑
├── 储能电站 ──→ 安全与经济性
├── 航空航天 ──→ 极端可靠性要求
└── 消费电子 ──→ 用户体验
        │
        ▼
    准确SOH估计 → 健康管理 → 安全运行 + 维护决策
```

## 现有方法的痛点

### 物理模型方法

| 优点 | 缺点 |
|------|------|
| 稳定、可解释 | 不同化学体系需要不同参数 |
| 有物理意义 | 计算成本高 |
| 外推能力强 | 电化学方程复杂难解 |

代表性工作：

- Dakin退化方法（线性退化）
- Arrhenius温度模型 + Wiener过程
- SEI膜生长模型
- P2D Newman模型

### 数据驱动方法

| 优点 | 缺点 |
|------|------|
| 精度高 | 泛化性差 |
| 效率高 | 依赖特征工程 |
| 无需物理知识 | 需要大量数据 |

代表性工作：

- 支持向量机（SVM）
- 高斯过程回归（GPR）
- 深度神经网络（DNN/CNN）
- 从IC/DV曲线提取特征

## 本文的切入点

### 一个关键观察

> 放电过程是用户特异的，但充电过程是固定且规范的。一旦开始充电，电池被充满的概率很高。

因此：**从充电曲线提取特征**比放电曲线更通用。

### PINN的优势

Physics-informed Neural Network = 物理知识 + 神经网络

```
物理知识的作用:
├── 减少训练数据需求（小样本学习）
├── 提高模型稳定性（物理约束）
├── 增强可解释性（退化动力学）
└── 支持迁移学习（通用物理规律）
```

### 本文的B2架构定位

根据Aykol等人的分类框架：

| 类别 | 方法 | 特点 |
|------|------|------|
| A1-A3 | Sequential Integration | 物理模型和ML模型独立 |
| **B1-B2** | **Hybrid** | **物理方程与ML真正融合** |

本文属于 **B2架构**：将退化动力学方程直接作为PDE约束嵌入神经网络训练。

## 研究目标

1. 提出通用特征提取方法（适用于不同电池类型）
2. 设计B2级PINN（物理方程与网络真正融合）
3. 验证小样本学习能力
4. 验证跨数据集迁移能力
