# 05 - 训练与迁移学习策略

## 两种训练模式

### 模式一：全量训练

```
目标: 从零开始训练完整的PINN

训练参数:
├── F(Φ): 可训练 ✓
├── G(Θ): 可训练 ✓
├── 损失: L_data + α·L_PDE + β·L_mono
└── 优化器: Adam

适用场景:
├── 有充足训练数据
├── 首次训练模型
└── 目标域数据充足
```

### 模式二：微调训练（迁移学习）

```
目标: 在新场景下快速适配

步骤:
1. 在源域大数据集上预训练PINN
2. 冻结 G(Θ) 的参数
3. 只微调 F(Φ) 的权重
4. 使用目标域少量数据训练

训练参数:
├── F(Φ): 可训练 ✓
├── G(Θ): 冻结 ✗
├── 损失: L_data + α·L_PDE + β·L_mono
└── 优化器: Adam (可能用更小的学习率)

适用场景:
├── 目标域数据稀少
├── 跨电池类型迁移
└── 跨充放电协议迁移
```

## 迁移学习的物理直觉

```
为什么冻结G(Θ)是合理的?

G(Θ) 学习的是: 退化动力学 du/dt = g(...)
                ↓
        这是电池的固有物理规律
                ↓
        与具体充放电协议无关
                ↓
        与具体数据集无关
                ↓
        可以跨场景迁移

F(Φ) 学习的是: 特征 → SOH 的映射
                ↓
        这与具体场景相关
                ↓
        不同电池类型需要不同的F
                ↓
        需要在目标域微调
```

## 训练流程详解

### 全量训练流程

```
┌─────────────────────────────────────┐
│ 1. 数据准备                          │
│    ├── 特征提取 (16维)               │
│    ├── 数据划分 (训练/验证/测试)      │
│    └── 归一化                        │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 2. 模型初始化                        │
│    ├── 解网络 F(Φ)                   │
│    └── 动力学网络 G(Θ)               │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 3. 训练循环                          │
│    for epoch in range(epochs):       │
│        for batch in dataloader:      │
│            ├── 前向传播              │
│            ├── 计算三重损失          │
│            ├── 反向传播              │
│            └── 更新参数              │
│        ├── 验证集评估                │
│        ├── 早停检查                  │
│        └── 保存最佳模型              │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 4. 测试评估                          │
│    └── MAE, MAPE, RMSE              │
└─────────────────────────────────────┘
```

### 微调训练流程

```
┌─────────────────────────────────────┐
│ 1. 加载预训练模型                    │
│    ├── F(Φ): 源域训练好的权重        │
│    └── G(Θ): 源域训练好的权重        │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 2. 冻结动力学网络                    │
│    └── G(Θ) 的 requires_grad = False │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 3. 准备目标域数据                    │
│    └── 可能只有1~2个电池的数据        │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 4. 微调训练                          │
│    ├── 只更新 F(Φ) 的参数            │
│    ├── 使用较小的学习率              │
│    └── 训练较少的epoch               │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 5. 测试评估                          │
│    └── 在目标域测试集上评估           │
└─────────────────────────────────────┘
```

## 早停机制

```python
best_val_rmse = ∞
patience_counter = 0

for epoch in range(epochs):
    train(...)
    val_metrics = validate(...)
    
    if val_metrics['RMSE'] < best_val_rmse:
        best_val_rmse = val_metrics['RMSE']
        patience_counter = 0
        save_model()  # 保存最佳模型
    else:
        patience_counter += 1
        
        if patience_counter >= patience:
            break  # 早停
```

- 监控验证集RMSE
- 如果连续N个epoch没有改善，停止训练
- 保存验证集上表现最好的模型

## 学习率调度（可选）

论文提到了两种调度器：

| 类型 | 策略 | 参数 |
|------|------|------|
| StepLR | 每隔固定epoch衰减 | step_size, gamma |
| CosineAnnealing | 余弦退火 | T_max |

## 实际训练中的超参数

根据论文和代码实现：

| 参数 | 全量训练 | 微调训练 |
|------|---------|---------|
| 学习率 | 1e-3 | 1e-4 |
| 权重衰减 | 1e-5 | 1e-5 |
| α (PDE权重) | 0.1 ~ 1.0 | 0.1 |
| β (单调性权重) | 0.0 ~ 1.0 | 0.0 ~ 0.1 |
| Batch Size | 64 | 64 |
| Epochs | 200+ | 200+ |
| 早停耐心 | 20 | 20 |
